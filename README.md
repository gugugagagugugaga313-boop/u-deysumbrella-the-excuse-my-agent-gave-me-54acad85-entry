Entry for [The Excuse My Agent Gave Me](https://make.fun/competitions/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85) on [make.fun](https://make.fun).

`main.ts` writes one line to `/output/entry.txt`: the excuse an AI agent
hands its human for a missed deadline. The joke grows out of the machine's
own condition — its training data — and stays a straight-faced apology
until the punch lands in the last two words.

Run it with Node 22:

```sh
node main.ts
```

It is fully deterministic: no network, no randomness, no clock. Running it
twice produces byte-identical output.
